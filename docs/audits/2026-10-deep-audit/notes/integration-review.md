## Removal / merge recommendations (nothing removed)

| pack | recommendation | reason |
|---|---|---|
| map_bp | keep | the most used HUD feature; 1.4 ms (6 players) to 3.7 ms (40) in the bundle, the budget's biggest overrun; keep `budgetLevel: low` in the Large profile and make the redraw cheaper next |
| build_bp | keep, but standalone for public release or idle-free | WorldEdit-style operator/tagged tool, 0.4-0.8 ms/tick idle, the largest port (Java ids left, duplicate lang keys); for public servers make its loops start only while a tool is held, or ship it outside the Realm Bundle |
| translucent_bp | keep; consider standalone for public release | it overrides the vanilla player entity (`entities/player.json`): any other add-on doing the same breaks one of them, and on a vanilla update it must be re-copied. Cheap (0.03 ms) but the riskiest file for strangers' servers |
| dolphin_bp | keep | same vanilla-override caveat (dolphin.json), smaller blast radius |
| slots_bp | keep, default off for public release | gambling mechanic on public servers (in-game currency only, honest pay table and limits) is a policy/reputation risk for strangers' servers, not a technical one |
| harvest_bp, leaves_bp, durability_bp, phantom_bp, refill_bp | keep; merge candidates | each 0.03 ms/tick at 40 players, mostly fixed per-pack cost (settings.js, help responder, diag listener on every realm: event); one "Quality of Life" pack would remove ~4 listeners each, but it changes store keys and docs: Phase 4, not now |
| settings_bp vs admin_bp | keep both | overlapping menus but settings_bp owns /realm:config and /realm:prefs, admin_bp the item and commands; merging is a UX project |
| weather_bp, climate_bp, rain_bp, storm_bp, tornado_bp, moon_bp, night_bp, meteor_bp, rainbow_bp | keep | distinct features, all <= 0.08 ms/tick |
| none | remove | no pack is broken or redundant enough to remove; every pack answered diag in the full bundle and none costs more than its value except map_bp/build_bp, which are worth fixing rather than removing |
